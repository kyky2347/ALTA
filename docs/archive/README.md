# Historical records

This directory contains superseded milestone gates and early design material.
It exists for engineering traceability. Current behavior is defined by the
root README, `docs/architecture/overview.md`, current operations guide, source
contracts, migrations, and tests.

Historical claims must not be interpreted as current performance, security, or
Alpha evidence.

- [Initial Trader Society design](initial-design.md)
- [Bootstrap milestone record](bootstrap-milestones.md)

The original working notes were consolidated because they repeated obsolete
commands, intermediate test counts, and design proposals that no longer match
the current implementation. The summaries retain the decisions and acceptance
boundaries that remain useful without publishing the obsolete working text.
